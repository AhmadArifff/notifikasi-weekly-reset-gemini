# notifikasi-weekly-reset-gemini
## ChronosAI — Multi-Agent Reset Pulse & Financial Watcher

Aplikasi Progressive Web App (PWA) generasi baru yang dirancang untuk memantau kuota mingguan/rolling akun AI (*Antigravity, Claude Code, Cursor, OpenCode, Gemini, Codex*) serta manajemen siklus penagihan langganan finansial.

---

### 📂 Dokumen & Aset Utama Proyek

1. 📄 **[PRD.md](PRD.md)**: *Product Requirements Document v1.4.0* — Arsitektur sistem, skema PostgreSQL Supabase dengan RLS, logika rolling window/weekly reset, skema promo/trial bertahap, dan notifikasi terpisah (Mobile Web Push vs Laptop Notification Center).
2. 🛡️ **[RULES.md](RULES.md)**: *Engineering Rules & Anti-AI-Slop Standards* — Aturan pengembangan ketat, sanitasi Zod, kontrak living prototype, performa canvas Matrix Rain, dan standar kontras tinggi WCAG AA.
3. 🎮 **[prototype.html](prototype.html)**: *Living Interactive HTML Prototype* — Prototipe interaktif yang dapat langsung dibuka di browser dengan 3 tema (*Kawaii Dream, Cyber-Virus Matrix, Obsidian Pro*), 3D Three.js WebGL canvas, live countdown ticker, dan pusat notifikasi lonceng laptop.

---

### 🎨 Tiga Tema Interaktif (Tri-Theme Personality)

* 🎀 **Kawaii Dream (Feminine Pastel)**: Palet strawberry milk & peach mochi, kartu awan putih kontras tinggi, tombol membal squishy mochi, dan maskot 3D kawaii.
* 💀 **Cyber-Virus Matrix (Hacker Extreme)**: Layar hitam pekat dengan Matrix Digital Rain canvas, teks scramble auto-typing, dan cyber skull glitch.
* 💎 **Obsidian Pro High-Tech**: Glassmorphism gelap premium dengan Border Beam Magic UI dan tipografi modern.
